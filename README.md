### `gherkin-rule-check`

- **用途**：檢查 `.feature` 檔中每個 Scenario 是否只驗證一條規則，列出需要拆分的 Scenario。
- **使用時機**：寫完規格、交給 AI 產生測試程式碼之前。
- **設計想法**：一個 Scenario 混入多條規則時，AI 產生的測試容易漏掉其中一條。我先把規則拆開，後續的測試與實作就能逐條對應回規格。
- **驗證狀態**：已在個人專案中實際使用。
